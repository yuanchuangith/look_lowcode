## 已知限制

- 这是有界静态分析，不是编译器源映射、运行路径覆盖或可信外键推断。动态目标、不可确认的参数声明、复杂计算和分支合并继续保留候选/未解析。
- 分组方法按精确 key 识别；生成方法命名模式不同或多候选时回退，不猜测“精确定位”。词法引用只说明语法上引用，并不证明字段值类型、业务去重正确或运行可达。
- 当前作用域的锚点需有已确认动作身份；仅有页面或多动作目标时保留澄清/候选流程。纠正与排除项由会话 Skill 维护，不是一个独立业务语义解析器。
- 字节预算针对结构化 UTF-8 JSON，不含 MCP 传输封装；分页偏移按 Unicode 字符计数。证据被省略时仍需续读后再下确定结论。
- 没有执行真实培训生成、提交、推送、全库刷新或线上认证检查；安装成功与静态测试通过不等于业务流程运行验证。
