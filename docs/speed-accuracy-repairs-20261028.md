# Look 速度与准确性修复（2026-10-28）

源码版本为 `0.5.7`，基线为 `4b4c278deb6f4712ce46d5bbb9081e839ffd3883`。本轮仅修改源码、技能和离线测试；没有读取凭据、连接业务库或更新客户端安装。当前聊天和已安装缓存不会自动加载源码变更。

## 实际行为

- CPM 搜索返回 `search_complete/scan_complete/scanned_count/stop_reason(s)`、正文截断和读取失败计数。达到结果或文件上限立即停止，不继续枚举；恰好达到边界也保守标为未查全。保留文件与正文预算，不提供未经快照绑定的续读游标；通过缩窄查询或精确页面检查继续取证。
- 动态异常预诊断复用专用异常工具的摘要、分页与依赖重验缓存。保留 `input_kind/diagnosis/source_hints/next_tools`，预算覆盖完整嵌套结构。上下文及当前证据绑定游标，大上下文可从 envelope 片段恢复；续读继承原参数，避免重复输出长异常栈。自然语言返回结构保留。
- 工具 schema 暴露当前发布/草稿、摘要/完整枚举，以及现有分页和字节范围。错误输入在 MCP 验证时拒绝，不创建数据库服务。技能仅在诊断已给出唯一完整身份时省去重复身份查询，当前发布复查保留。
- 索引重建每次重新读取当前字节、计算 SHA-256；按仓库、层、相对路径、摘要、解析器版本及配置依赖复用纯解析结果。删除与重命名以当前文件集合为准，完整重做跨文件关联和原子 generation 发布。缓存仅在进程内，128项、估算对象32 MiB、单项4 MiB；不是进程内存硬上限，不落盘源码。`force=true` 全量重解析，持久索引仍为 v4。
