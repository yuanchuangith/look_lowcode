# Component Filter Audit

只在排查下拉、`DataFilter`、无可选值、值被清空、默认值或事件覆盖过滤时读取本文件。目标是证明同一组件在所有执行入口下的最终候选范围，不修改 ActionDesign 或业务数据。

## 1. 先锁定规则极性

把用户原话归入三栏：

```text
当前现象：例如“岗位矩阵申请时仍能选择所有试卷”
期望规则：例如“只能选择当前文件版本对应的试卷”
无匹配时行为：例如“下拉为空，不能选择”
```

“可以选择全部”没有明确归类时，不能写“已满足”或“未满足”。用户纠正规则后复用已确认的页面、动作、RefId、组件和节点，只重算判定。

文件试卷场景只有在用户确认后，才采用以下业务不变量：

```text
允许集合 = 与 file_id 且 file_version 同时对应的试卷
无对应关系 = 空集合，下拉不可选择
```

不要把仅按 `testpaper_status`、`testpaper_type` 或全部有效试卷过滤误判为“文件对应试卷”。

## 2. 页面优先定位

用户给出流程页面而非动作 code 时：

1. 每个业务页面名称只调用一次 `search_pages`。
2. 确认首位候选的显示名称、Route、Id、OutId 和匹配方式。
3. 用精确 Route/Id/OutId 调用 `list_page_actions`。
4. 根据动作显示名称、code、RefId 和子表单用途消歧。
5. 后续复用这些会话锚点，不读取整个应用页面列表。

## 3. 两阶段读取

第一阶段：只定位。

- `inspect_action(include_params=false, include_generated_csharp=false)`。
- 只保留动作、设计版本、分组、画布行/索引、节点、组件身份和 `facts`。
- 通过 `DataFilter` 节点的 `component_key`、标签、类型和 `model_key` 确认目标组件。

第二阶段：聚合同一组件。

- 调用 `inspect_component_filters(identifier, component, include_params=false)`。
- 必须读取返回的全部 writers，不能停在第一个初始化节点。
- 仅当某个 writer 的扁平过滤事实不足时，使用精确组件 key 再传 `include_params=true`。
- 不主动读取生成 C#；过滤配置判断通常不需要 C#。

## 4. 全写入点审计

逐个核对：

- 执行阶段：初始化、默认值、事件绑定、字段变更、组件事件或其他阶段。
- 可见定位：动作/RefId、分组名称/Key、画布行/索引、节点名称/Key/类型。
- 组件身份：key、标签、组件类型、model key。
- 完整过滤事实：根逻辑、每个字段、运算符、表达式、数据类型和嵌套逻辑路径。
- 父级分支：全部 `IF`、`Else IF`、`Else` 及其完整条件。
- 相邻节点：上一个和下一个可见节点。
- 覆盖关系：后执行 writer 是否会替换前一过滤；互斥分支分别判断，不能合并成一条必经路径。

初始化满足规则不代表最终满足。任一可达的字段变更或事件 writer 恢复为“全部有效试卷”，最终结论仍是不满足。

## 5. 输出矩阵

先给结论，再给最小矩阵：

| 入口/阶段 | 父条件 | 最终 DataFilter | 无匹配行为 | 是否满足不变量 |
| --- | --- | --- | --- | --- |
| 初始化 | 完整条件 | 完整字段/运算符/表达式 | 空/全部/未知 | 是/否/待确认 |
| 默认值 | 完整条件 | 完整字段/运算符/表达式 | 空/全部/未知 | 是/否/待确认 |
| 字段变更/事件 | 完整条件 | 完整字段/运算符/表达式 | 空/全部/未知 | 是/否/待确认 |

最终判定必须说明：

- 审计到多少个同组件 writer，是否覆盖全部分组。
- 哪个可达 writer 最后决定候选范围。
- 是否同时约束 `file_id + file_version`。
- 无映射时是空集合，还是因过滤缺失而退化成全部候选。
- 结论属于静态发布设计、草稿差异还是已经完成运行验收。

## 6. Token 预算

- 页面候选最多 20 条，页面动作最多 50 条。
- `inspect_action` 默认最多回传 20 个节点；超过时按提示缩小。
- 完整参数一次不得覆盖超过 10 个节点。
- 黄金场景不调用全应用页面扫描、不做宽范围完整参数检查、不读取无关生成 C#。
- 目标：单次 MCP JSON 小于 64 KB，完整页面定位与两个动作过滤审计累计小于 120 KB。
